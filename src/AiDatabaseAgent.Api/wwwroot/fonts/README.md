# Fonts

Self-hosted copies of the AI Engineering Foundry brand typefaces (same files as the public site),
served from this origin so the UI needs no third-party requests and works with a strict CSP.

- Big Shoulders Display (weight 900) — headlines
- IBM Plex Sans — body and UI
- IBM Plex Mono (400, 500) — labels, SQL, numbers

All three families are licensed under the SIL Open Font License 1.1 (https://openfontlicense.org).
